# ARENA RUSH – אב-טיפוס דפדפן

משחק יריות בגוף ראשון בהשראת RIVALS, עם מולטיפלייר, צ'אט מסונן ובוטים. רץ בדפדפן, במחשב ובטלפון.
זה אב-טיפוס לבדיקת תחושת המשחק. גרסת Unity נמצאת בתיקייה `unity`.

## הפעלה
```bash
cd RIVALS-GO
npm install
npm start          # http://localhost:3000
```
חברים באותה רשת נכנסים לכתובת `http://<IP-של-המחשב>:3000`. משתני סביבה: `PORT`, ו-`BOTS` (כמה לוחמים בסך הכול הבוטים משלימים, ברירת מחדל 4).

## מה יש
- כולם נגד כולם עד 12 שחקנים, ראשון ל-25 הריגות או 5 דקות. בוטים ממלאים את הזירה כשיש מעט שחקנים.
- 4 נשקים (רובה סער, שוטגאן, צלף עם סקופ, אקדח). ערכי האיזון נמצאים ב-`shared/weapons.js`.
- השרת מחליט על פגיעות ונזק, כולל פיצוי השהיה (lag compensation), בדיקת קצב ירי ובדיקת מהירות תנועה.
- תחושת משחק: סימני פגיעה, מספרי נזק, צליל שונה לראש ולהריגה, רתיעה, הבזק, רצפי הריגות (DOUBLE KILL…), XP ורמות.
- צ'אט: מסנן קללות, קישורים ומידע אישי, אזהרות והשתקה זמנית, הגבלת קצב, הודעות מהירות (B), ופקודות `/mute`, `/unmute` ו-`/report`.
- שליטה במובייל: ג'ויסטיק, החלקה לכיוון וכפתורים.

## אימון בלי שרת
אם אין שרת זמין, המשחק עובר לבד ל"אימון נגד בוטים" שרץ כולו בדפדפן (`shared/game.js` רץ גם בשרת וגם בדפדפן).

## אפליקציית אנדרואיד (APK)
הקובץ המוכן: `android/ArenaRush.apk` (גרסה 0.8: אימון נגד בוטים בלי אינטרנט, חדרים עם חברים וצ'אט קולי דרך האינטרנט, 10 דמויות, ידיים בגוף ראשון). זה APK לבדיקות. להעלאה ל-Google Play צריך AAB, לפי `docs/STORE_RELEASE.md`.

**התקנה בטלפון:**
1. מעבירים את `ArenaRush.apk` לטלפון (מייל לעצמך, Google Drive או כבל USB).
2. פותחים את הקובץ בטלפון. אם מופיעה הודעה, מאשרים "התקנה ממקורות לא ידועים" לאפליקציה שממנה פתחת.
3. לוחצים התקן, ואחר כך פותחים את **Arena Rush**.

**בנייה מחדש** (Linux, אחרי שינוי בקוד): `android/build.sh`.

## גרסת רשת: התחברות עם Gmail ומציאת שחקנים
- **משחק מהיר:** מצרף אותך לחדר הציבורי הכי מלא שיש בו מקום, כדי שתפגוש שחקנים אחרים.
- **חדר פרטי:** יוצר קוד בן 5 תווים. חברים מצטרפים עם הקוד, או בקישור `?room=CODE`.
- **הזמנת חבר לפי Gmail:** בצ'אט במשחק כותבים `/invite friend@gmail.com`. אם החבר מחובר עם Google, הוא מקבל הזמנה עם כפתור "הצטרף". הפקודה `/room` מציגה את קוד החדר.
- **פרטיות:** כתובות Gmail לא מוצגות לשחקנים אחרים. במשחק מופיע רק השם הפרטי.

### הפעלת התחברות עם Google (פעם אחת)
1. נכנסים ל-[Google Cloud Console](https://console.cloud.google.com/apis/credentials), ושם בוחרים **Create credentials** ואז **OAuth client ID** מסוג **Web application**.
2. ב-**Authorized JavaScript origins** מוסיפים את כתובת האתר של המשחק, למשל `https://arena-rush.onrender.com`, וגם `http://localhost:3000` לבדיקות.
3. מעתיקים את ה-Client ID ומפעילים את השרת איתו:
   ```bash
   GOOGLE_CLIENT_ID=xxxx.apps.googleusercontent.com npm start
   ```
בלי `GOOGLE_CLIENT_ID` המשחק עובד כרגיל, עם אורחים, חדרים וקודים, אבל בלי התחברות ובלי הזמנות לפי Gmail.

### העלאה לאינטרנט
כל שירות שמריץ Node.js ותומך ב-WebSocket מתאים, למשל Render, Railway או Fly.io. ב-Render:
1. **New** ואז **Web Service**, ובוחרים את המאגר הזה.
2. **Root Directory:** ריק (שורש הריפו), ‏**Build:** `npm install`, ‏**Start:** `npm start`.
3. ב-Environment מוסיפים `GOOGLE_CLIENT_ID`.

## מודלים
דמויות ונשקים אמיתיים (קבצי GLB) בתיקייה `public/models`. הרישיונות מפורטים ב-`public/models/CREDITS.md`. אם מודל לא נטען, המשחק חוזר לדמויות ולנשקים הפשוטים.

## מסך פתיחה: שם, דמות ושרת
- **דמות:** 3 דמויות לבחירה עם תצוגה תלת-ממדית מסתובבת. שחקנים אחרים רואים את הדמות שבחרת.
- **שרתים:** הרשימה נטענת מ-`public/servers.json`, ומוצגים בה זמן תגובה (ms) ומספר המחוברים בכל שרת. "אימון במכשיר" עובד בלי אינטרנט.

**הוספת שרת:** מוסיפים שורה ל-`public/servers.json`, למשל:
```json
{ "id": "eu1", "name": "אירופה 1", "region": "פרנקפורט", "url": "https://arena-rush-eu.onrender.com" }
```

**החלפת דמויות:** שמים את קבצי ה-GLB ב-`public/models/characters/` ומשנים את `file` ב-`shared/characters.js`, למשל `"characters/hero.glb"`. דמות עם שלד Mixamo מקבלת אנימציות הליכה וריצה וידיים על הנשק. ב-APK צריך להוסיף את הקבצים גם ל-`android/entry.js`.

## גרסת מחשב (Windows)
```bash
cd desktop
npm install
npm run dist      # dist/Arena Rush-<גרסה>-win.zip
```
פותחים את ה-zip ומריצים `Arena Rush.exe`. כדי להתחבר לשרת אונליין, מוסיפים אותו ל-`desktop/servers.json`. F11 מעביר למסך מלא.

המדריך המלא (Steam ו-Google Play, כולל עלויות ועצירות לאישור) נמצא ב-`docs/STORE_RELEASE.md`. טיוטת מדיניות פרטיות נמצאת ב-`docs/PRIVACY_POLICY.md`.

## משחק עם חברים באינטרנט (בלי שרת)
1. בלשונית **"עם חברים"** לוחצים **"פתח חדר"** ומקבלים קוד בן 5 תווים. הקוד מופיע גם במשחק, בראש המסך, ולחיצה עליו מעתיקה הזמנה.
2. החברים מקלידים את הקוד ולוחצים **"הצטרף"**, מהדפדפן, מה-APK או מגרסת המחשב. קישור עם `?join=CODE` ממלא את הקוד לבד.
3. המשחק רץ במכשיר של מי שפתח את החדר, והמכשירים מתחברים ישירות (WebRTC). שירות PeerJS החינמי רק מכיר בין המכשירים.

**מגבלות:**
- כשפותח החדר יוצא, החדר נסגר.
- יש רשתות (חלק מרשתות העבודה והסלולר) שחוסמות חיבור ישיר. במקרה כזה צריך לנסות רשת אחרת, או להוסיף שרת TURN (עולה כסף).
- בחדרי חברים אין חנות ואין חשבונות, ופותח החדר יכול תיאורטית לרמות. לתחרות אמיתית צריך שרת.
