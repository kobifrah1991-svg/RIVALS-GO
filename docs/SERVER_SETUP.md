# הפעלת שרת

## מקומי (חינם)
```bash
cd RIVALS-GO
npm install
npm start               # http://localhost:3000
```
חברים באותה רשת נכנסים לכתובת `http://<IP-של-המחשב>:3000`. בפעם הראשונה Windows ישאל אם לאפשר גישה ברשת: מאשרים "רשתות פרטיות" בלבד.

## משתני סביבה

| משתנה | מה עושה | ברירת מחדל |
|---|---|---|
| `PORT` | פורט השרת | `3000` |
| `BOTS` | לכמה לוחמים הבוטים משלימים את החדר | `4` |
| `GOOGLE_CLIENT_ID` | מפעיל התחברות עם Google (הוראות ב-`README.md`) | כבוי |
| `ADMIN_CODE` | קוד סודי לכניסת מפעיל כ-Owner (`/adminlogin`) | כבוי |
| `DATA_DIR` | תיקייה לחשבונות השחקנים (`accounts.json`), לחסימות, ללוג אדמין ול-`admins.json`. בשרת אינטרנט חייבת להיות על דיסק קבוע, אחרת החשבונות יימחקו בכל פריסה | `data/` |
| `TRUST_PROXY` | כשהשרת מאחורי פרוקסי (Render וכדומה), לוקח IP מ-`X-Forwarded-For` | כבוי |

## בדיקת תקינות
- `GET /health` מחזיר `ok`.
- `GET /config` מחזיר את מספר המחוברים והחדרים. רשימת השרתים במסך הפתיחה משתמשת בכתובת הזו כדי למדוד פינג.

## הוספת שרת לרשימה
ב-`public/servers.json`:
```json
[
  { "id": "here", "nameKey": "srv.here", "regionKey": "srv.hereRegion", "url": "" },
  { "id": "eu1", "name": "Europe 1", "region": "Frankfurt", "url": "https://arena-eu.example.com" }
]
```
`url` ריק פירושו השרת שממנו נפתח המשחק. שרת שלא עונה מסומן "לא זמין". הרשימה מציגה רק נתונים אמיתיים, בלי נתוני דמו.

## אירוח באינטרנט
**לא בוצע.** לפי התוכנית, פריסה מחייבת אישור מפורש של בעל הפרויקט, כי ייתכנו עלויות. אפשרויות שתומכות ב-Node.js ו-WebSocket הן Render, ‏Railway ו-Fly.io. לכל אחת מגבלות שונות במסלול החינמי, וכדאי לבדוק מחירים עדכניים לפני שמחליטים.
