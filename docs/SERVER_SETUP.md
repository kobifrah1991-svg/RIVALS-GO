# הפעלת שרת

## מקומי (חינם)
```bash
cd RIVALS-GO
npm install
npm start               # http://localhost:3000
```
חברים באותה רשת נכנסים לכתובת `http://<IP-של-המחשב>:3000`. בפעם הראשונה Windows ישאל אם לאפשר גישה ברשת: מאשרים "רשתות פרטיות" בלבד.

## משתני סביבה

| משתנה | מה עושה | ברירת מחדל |
|---|---|---|
| `PORT` | פורט השרת | `3000` |
| `BOTS` | לכמה לוחמים הבוטים משלימים את החדר | `4` |
| `GOOGLE_CLIENT_ID` | מפעיל התחברות עם Google (הוראות ב-`README.md`) | כבוי |
| `ADMIN_CODE` | קוד סודי לכניסת מפעיל כ-Owner (`/adminlogin`) | כבוי |
| `DATA_DIR` | תיקייה לחשבונות השחקנים (`accounts.json`), לחסימות, ללוג אדמין ול-`admins.json`. בשרת אינטרנט חייבת להיות על דיסק קבוע, אחרת החשבונות יימחקו בכל פריסה | `data/` |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | שמירת חשבונות (קרדיטים, XP ופריטים) ב-Upstash Redis, כך שהם לא נמחקים כשהשרת מאתחל | כבוי (קובץ מקומי בלבד) |
| `TRUST_PROXY` | כשהשרת מאחורי פרוקסי (Render וכדומה), לוקח IP מ-`X-Forwarded-For` | כבוי |

## בדיקת תקינות
- `GET /health` מחזיר `ok`.
- `GET /config` מחזיר את מספר המחוברים והחדרים. רשימת השרתים במסך הפתיחה משתמשת בכתובת הזו כדי למדוד פינג.

## הוספת שרת לרשימה
ב-`public/servers.json`:
```json
[
  { "id": "here", "nameKey": "srv.here", "regionKey": "srv.hereRegion", "url": "" },
  { "id": "eu1", "name": "Europe 1", "region": "Frankfurt", "url": "https://arena-eu.example.com" }
]
```
`url` ריק פירושו השרת שממנו נפתח המשחק. שרת שלא עונה מסומן "לא זמין". הרשימה מציגה רק נתונים אמיתיים, בלי נתוני דמו.

## אירוח באינטרנט: שרת פעיל עם ניקוד וכסף שנשמרים
הכול מוכן בריפו, ולא נדרש תשלום. נשאר רק לפתוח את החשבונות. את זה **רק בעל הפרויקט** יכול לעשות, כי צריך להירשם.

**1. מסד נתונים חינמי לשמירת ניקוד וכסף (Upstash, בלי כרטיס אשראי):**
1. נרשמים ב-https://upstash.com (אפשר עם חשבון Google או GitHub).
2. יוצרים **Redis Database** בתוכנית Free, באזור קרוב (למשל Frankfurt).
3. בעמוד המסד, בחלק **REST API**, מעתיקים שני ערכים: `UPSTASH_REDIS_REST_URL` ו-`UPSTASH_REDIS_REST_TOKEN`.

**2. השרת עצמו (Render, תוכנית חינמית):**
1. פותחים את https://render.com/deploy?repo=https://github.com/kobifrah1991-svg/RIVALS-GO ונרשמים עם GitHub.
2. Render קורא את הקובץ `render.yaml` ומבקש את שני הערכים מ-Upstash. מדביקים אותם ולוחצים **Apply**.
3. אחרי כמה דקות השרת עולה בכתובת `https://rivals-go.onrender.com`. אם השם תפוס, Render נותן כתובת אחרת: מעדכנים אותה ב-`shared/servers.js`.
4. בדיקה: `https://rivals-go.onrender.com/health` מחזיר `ok`.

**מה מקבלים:**
- **סנכרון:** השרת מכריע פגיעות, ניקוד ומוות לכל השחקנים בחדר.
- **שמירה:** קרדיטים, XP, רמה ופריטים נשמרים ב-Upstash, גם כש-Render מאתחל את השרת.
- **בכל הגרסאות:** השרת מופיע ברשימת השרתים באתר, ב-APK ובגרסת המחשב.
- **זיהוי שחקן:** שחקן אורח מזוהה לפי מזהה שנשמר במכשיר. כדי לשמור התקדמות בין מכשירים צריך התחברות עם Google (`GOOGLE_CLIENT_ID`, הוראות ב-README).

**מגבלות של התוכנית החינמית:**
- **השרת "נרדם"** אחרי כ-15 דקות בלי שחקנים. החיבור הראשון אחרי זה לוקח כחצי דקה עד דקה, ובינתיים השרת יופיע ברשימה כ"לא זמין". לוחצים "רענן" אחרי רגע.
- **חסימות ולוג אדמין** נשמרים בדיסק של השרת, ולכן נמחקים באתחול. הניקוד והכסף לא נמחקים, כי הם ב-Upstash.
- **שרת שלא נרדם:** ב-Render זה בתשלום (כ-7$ לחודש). **דורש אישור מפורש** של בעל הפרויקט.
