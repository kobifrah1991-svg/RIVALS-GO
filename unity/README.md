# ARENA RUSH – פרויקט Unity

משחק יריות בגוף ראשון בסגנון RIVALS, עם מולטיפלייר, צ'אט מסונן ובוטים. נבנה לפי `docs/GDD_Arena_Rush.md`, שלבים M0 ו-M1 ועוד צ'אט מ-M5.

## התקנה בפרויקט שלך (פעם אחת)

1. **הורד את הקבצים:** ב-GitHub פתח את הענף `claude/peaceful-dijkstra-vz1rep`, לחץ **Code** ואז **Download ZIP**, וחלץ את הקובץ.
2. **העתק לתוך הפרויקט:** את **התוכן** של התיקייה `unity` (התיקיות `Assets` ו-`docs` והקבצים `CLAUDE.md` ו-`.gitignore`) העתק אל:
   ```
   D:\GAME CREATE\RIVELS GO\RIVELS GO\
   ```
   כך שהתיקייה `Assets\ArenaRush` תשב ליד שאר התיקיות של Unity. אם Windows שואל, אשר מיזוג תיקיות.
3. **חזור ל-Unity** וחכה שהייבוא יסתיים. בתפריט העליון יופיע תפריט חדש: **Arena Rush**.

## בדיקה מה חסר

בתפריט **Arena Rush** בחר **1. Check Project**. ייפתח חלון שבודק:

| בדיקה | מה עושים אם חסר |
|---|---|
| Unity 6 | להתקין Unity 6 LTS דרך Unity Hub |
| נתיב בלי רווחים | אזהרה בלבד. הנתיב שלך מכיל רווחים: במחשב זה בסדר, ולבנייה לאנדרואיד עדיף נתיב כמו `C:\Games\ArenaRush` |
| Netcode for GameObjects | כפתור **Install** בחלון (או **2. Install Missing Packages**) |
| Input System | כפתור **Install**. אם Unity מבקש להפעיל מחדש, לחץ Yes |
| URP | ליצור את הפרויקט מתבנית **Universal 3D (URP)** |
| Android / Windows Build Support | ב-Unity Hub: Installs, ואז ⚙ ו-Add modules |
| סצנת המשחק | כפתור **Build** (או **3. Build Game Scene**) |
| Run In Background | כפתור **Enable** |
| GDD, ‏CLAUDE.md ו-Git | לפי שלב 4 במדריך ההתקנה |

סדר העבודה: **1** (בדיקה), אחר כך **2** (התקנת חבילות), ואז **3** (בניית הסצנה).

## לשחק

1. פתח את `Assets/ArenaRush/Scenes/ArenaRush.unity` ולחץ ▶ Play.
2. **אימון נגד בוטים:** הכפתור הראשון.
3. **מולטיפלייר עם חברים באותה רשת:** מחשב אחד לוחץ "ארח משחק". השאר כותבים את ה-IP שמופיע אצל המארח ולוחצים "הצטרף". בפעם הראשונה Windows Firewall ישאל: אשר.
4. **בדיקה לבד עם שני חלונות:** File, ‏Build And Run. חלון אחד מארח, והשני מצטרף לכתובת `127.0.0.1`.

**שליטה:** WASD תנועה · רווח קפיצה · עכבר שמאלי ירי · ימני כוונת/סקופ · 1-4 או גלגלת להחלפת נשק · R טעינה · Tab ניקוד · Enter צ'אט · B הודעות מהירות · Esc תפריט. יש גם תמיכה בשלט (גיימפד).

**פקודות צ'אט:** `/mute שם` · `/unmute שם` · `/report שם סיבה`. הדיווחים נשמרים אצל המארח בקובץ `reports.txt`.

## מה עוד חסר לפי ה-GDD (השלבים הבאים)

- **מודלים אמיתיים:** כרגע הדמויות והנשקים עשויים מקוביות. מודלים מ-Blender ו-Mixamo יחליפו אותם.
- **מובייל:** ג'ויסטיק וכפתורי מגע (M0). בינתיים יש מקלדת, עכבר ושלט.
- **אונליין מחוץ לרשת הביתית:** Unity Relay, או מעבר ל-Photon Fusion 2 כמו שכתוב ב-GDD.
- **פיצוי השהיה (lag compensation)** לירי מדויק יותר אצל שחקנים עם פינג גבוה.
- **Unity Localization ותמיכה מלאה ב-RTL** במקום ההיפוך הזמני (`Rtl.Fix`).
- קרב קבוצות, עוד נשקים, חשבונות ושמירה בשרת (M2–M3).

## הערה טכנית

ה-GDD מציע Photon Fusion 2. התחלתי עם **Netcode for GameObjects** של Unity, כי הוא מותקן בלחיצה, לא דורש חשבון או מפתח, ומספיק לשלב M1. אם תרצה לעבור ל-Photon בהמשך, הלוגיקה (נזק, משחק, צ'אט) מופרדת כך שהמעבר אפשרי.
